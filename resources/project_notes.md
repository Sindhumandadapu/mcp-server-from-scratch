
# SmartTools MCP Server

SmartTools is a LangChain-powered multi-tool AI agent.

## Technologies

- Python
- Model Context Protocol (MCP)
- LangChain
- FastAPI
- Streamable HTTP
- STDIO

## Features

The calculator tool performs addition, subtraction,
multiplication and division.

The file search tool searches project documents
and returns relevant matching lines.

The Model Context Protocol allows AI applications
to communicate with external tools and resources.
